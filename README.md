# 家政服务临时取消与空跑费核算系统

客户临时取消订单时，**先看到可能产生的空跑费和完整计算依据，再决定是否提交取消**。
系统记录服务员出发、到场与客户取消的时间，一律采用**下单时锁定的收费规则快照**计费；
客服可对“是否到场”争议改判，原金额、改判结果与理由全程留痕、双方可查；
已付款订单扣费与退款分别入账，账本锁定后只能追加补收/退款单；
重复取消、重复退款重试只处理一次。

## 一条本地命令启动

```bash
./run.sh
```

- 页面： http://127.0.0.1:8000/
- 接口文档： http://127.0.0.1:8000/docs
- 首次启动自动建库并播种演示数据；页面右上角“重置演示数据”可随时还原。
- 环境变量：`HOST` / `PORT` / `APP_DB`（默认 `data/app.db`）。

依赖：Python 3.11+（FastAPI / SQLAlchemy 2 / Uvicorn），前端为本地化 Vue 3（`static/vendor/`，无需 npm 构建）。
依赖安装：`pip install -r requirements.txt`。

## 演示数据（8 个场景）

| 订单 | 场景 |
|---|---|
| OD-RACE | 待服务，专门用于“出发/取消同毫秒并发”临界演示 |
| OD-DEPART | 已出发未到场、已付款（30% 空跑费样例） |
| OD-ARRIVE | 已到场、已付款（60% 样例） |
| OD-FREE | 免费取消窗口内（提前 ≥120 分钟） |
| OD-UNPAID | 已出发、未付款（空跑费直扣） |
| OD-DISPUTE | 围栏外签到（约 400m）的到场争议，等客服核对改判 |
| OD-CANCELED | 已取消已退款，演示重复取消去重、退款重试幂等 |
| OD-REVIEWED | 初判 30% → 客服改判 60%，原金额保留 + 补收单追加 |

页面分区：订单总览 / 客户取消（预览→确认）/ 现场操作（出发、围栏内外签到）/
客服改判台 / 账本对账（含退款重试）/ 临界时序演示 / 收费规则。

## 三个重点核查项

1. **出发临界时间**：判定只看服务端事件流 `order_events.seq`。
   - 每个业务事务以 `BEGIN IMMEDIATE` 开启，SQLite 写锁串行化，seq 在事务内单调递增；
   - `client_at_ms` 仅留档，不参与任何计算，双方客户端时钟再矛盾也只有一个费用；
   - “临界时序”页可一键并发，10 次真实并发实测：出发先→30%（6000 分），取消先→0，无第三种结果。
2. **客服改判记录**：`cancellations.original_fee_cents` 永不改变，每次改判在 `reviews`
   追加一条（旧阶段/新阶段、旧金额/新金额、理由、签到定位证据、重算依据），双方共用
   `GET /api/orders/{id}/cancellation` 查看。差额只产生 `additional_charge` /
   `additional_refund` 追加流水。
3. **退款重试与原订单对账**：模拟支付网关与账本均以幂等键唯一约束；重试命中首笔流水即原样返回，
   绝不二次退款。对账口径恒为
   `预付充值 + 未付直扣空跑费 + 改判补收 − 取消退款 − 改判追加退款 == 当前有效空跑费`，
   网关净额（收−退）与之相等。账本页展示双平衡标记（账本 / 支付网关）。

## 其他规则要点

- **规则快照**：下单时把规则完整复制进 `orders.rule_snapshot`（JSON）。之后改价只影响新订单。
- **到场判定**：模拟定位接口按服务地址 300m 电子围栏判定；围栏外签到只存证据、不推进“已到场”，争议交客服。
- **锁账只追加**：取消结算完成即 `ledger_locked=true`；之后没有任何 UPDATE/DELETE，改判只追加单据。
- **金额**：全部以整数“分”存储，比例费用四舍五入，支持最低空跑费与封顶。

## 测试

```bash
python3 -m pytest tests/ -q
```

20 个用例，分组：

- `tests/test_critical_timing.py` — seq 判定、同毫秒临界、真实多事务并发两边胜负、快照不受改价影响；
- `tests/test_agent_review.py` — 原金额保留、多轮改判只追加、理由必填、签到定位证据入档；
- `tests/test_refunds_and_ledger.py` — 重复取消只收一次、退款重试不重退、预付/未付双口径对账、
  锁账后只追加、网关幂等键唯一稳定。

## 目录结构

```
app/            FastAPI 后端
  main.py         路由（含 /race-demo 临界演示）
  services.py     事务边界、取消结算、改判、退款重试、对账
  pricing.py      规则快照 + 空跑费计算依据（纯函数）
  models.py       SQLAlchemy 模型（事件流/取消单/改判/只追加账本/幂等）
  mock_services.py 模拟定位（电子围栏）与模拟支付网关（幂等）
  seed.py         演示数据
static/         Vue 3 单页（本地 vendor，无构建）
tests/          pytest
run.sh          一条命令启动
```
